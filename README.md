## Setup

```bash
pip install -r requirements.txt
```

---

## Step 1 — Run the notebook

Open `louvainnet_project.ipynb` in Jupyter and run all cells top to bottom.

This will:
- Download ego-Facebook from SNAP automatically
- Run all analysis (Parts A–D)
- Save `louvainnet_data.pkl` and `network_interactive.html`

If the SNAP download fails (403 error in restricted environments):
1. Download manually: https://snap.stanford.edu/data/facebook_combined.txt.gz
2. Extract and place at: `data/ego_facebook/facebook_combined.txt`
3. Re-run the notebook from Cell 3 onward

---

## Step 2 — Launch the dashboard

```bash
streamlit run app.py
```

The dashboard opens at `http://localhost:8501`

**Dashboard sections:**
- **Network Overview** — graph statistics + interactive Pyvis network
- **Centrality Analysis** — select any of 4 centrality measures, view top-N nodes + heatmap
- **Community Detection** — run Newman / Louvain / Label Propagation interactively with color-coded visualization
- **Research: Non-determinism** — quantified Louvain variance across 20 runs (LouvainNet motivation)
